Designing an Advent of Code puzzle

Published on 22 September 2026

For my work at Infi I designed a puzzle for Advent of Code. Each year, we sponsor Advent of Code and in the side bar on the Advent of Code website we then link to our own yearly puzzle. This post is about how I designed the puzzle and some of the challenges I encountered along the way. The puzzle can be found on Infi's Advent of Code page.

I already had a vague idea for what I wanted the puzzle to be about; speeding up a calculation that is presented as a loop over a large N where the result of the previous iteration feeds into the next iteration. The N will be large enough to make simply executing the loop infeasible. At first glance this would seem impossible due to the loop dependency, but of course there is some clever trickery you can do.

Turning an O(n) loop O(log(n))

As a demonstration, we are going to optimize a loop that computes a multiplication in the way mentioned above.

function mul(a: number, b: number) {
  let res = 0;
  while (b--) {
    res += a;
  }

  return res;
}

The function adds a b times to an accumulator that is initialized to 0. If we write out this expansion you get ((((0 + a) + a) ...) + a) with a occuring b times. I added the parentheses to clarify the order of the calculations, but from an algebraic perspective they add nothing because addition is associative.
